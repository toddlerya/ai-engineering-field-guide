# AI 工程实践指南 (AI Engineering Field Guide)

这是一份关于 AI 工程师角色定位、技能要求以及面试准备的**数据驱动型**实践指南。它是你了解和进阶 AI 工程的必备参考。

本指南的所有内容都建立在真实数据的基础之上：分析了 **4,894 份实际招聘需求**、真实的面试经历以及从业人员的实际分享。这并非由 AI 生成的无用信息堆砌而成，每一个观点和洞察都源自于对实际数据的定量分析与模式提炼。

这是一个正在持续完善的项目，我会积极添加更多内容。非常欢迎你的反馈与贡献，共同塑造这份指南。

可以 Star 本仓库以关注后续更新。如果想获取最新内容推送，欢迎订阅我的个人 Newsletter：[Alexey on Data](https://alexeyondata.substack.com/)。
