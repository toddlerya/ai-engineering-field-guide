# 作品集 (Portfolio)

如何选择、规划、构建并展示能在面试中深入探讨且可顺利完成的 AI 工程作品集项目。

一切从真实行业、真实企业和真实痛点出发。然后再去挑选适用的技术方案。

**推荐学习与开发路径**：

1. 了解项目类型
2. 选择合适的项目
3. 开始项目开发
4. 打磨优化项目
5. 展示与探讨项目
6. 避开常见错误
7. 学习项目创意与实例

对于 AI 工程来说，一个合格的作品集项目应该展示出超越提示词或 Jupyter Notebook 原型演示的工程深度。

**加分/展示信号**：
- 真实的受众和明确的问题
- 真实的输入数据
- 清晰明确的输出
- 单元/集成测试
- 模型/系统评测 (Evaluation)
- 日志或监控系统
- 可复现的构建与部署配置
- 详细说明设计决策和权衡的 README 文档

这一系列标准源自 [AI Engineering Buildcamp: From RAG to Agents](https://maven.com/alexey-grigorev/from-rag-to-agents) 训练营。Buildcamp 项目从选题与原型概念验证（POC）开始，逐步增加测试、评测、监控和最终的部署落地。
